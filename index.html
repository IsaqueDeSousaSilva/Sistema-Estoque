Bem-vindo ao Sistema

Este sistema permite o gerenciamento completo do estoque de uma loja, com cadastro de produtos, fornecedores, entradas, saídas e clientes.

Funcionalidades

  • Cadastro de produtos com preço, quantidade e categoria
  • Cadastro de fornecedores com CNPJ e contato
  • Registro de entradas e saídas de estoque
  • Cadastro de clientes para vendas
